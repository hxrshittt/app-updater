System Overview: The Two ApplicationsThe Analab QA system relies on two separate but connected software applications to function.Software 1: DataStreamer (Hardware Logger)Purpose: Communicates directly with the physical pressure sensors and test machinery.Main Responsibilities: Reads raw physical pressure over time and records it into a standard text file (.txt or .csv).Inputs: Raw electrical signals from physical hardware.Outputs: A data file containing two columns: Time (seconds) and Pressure.Software 2: Analab Pressure Decay Analyzer (v1.1)Purpose: The visual dashboard where operators interact with the test data.Main Responsibilities: Imports the data file, graphs the pressure curve, mathematically analyzes the leak rate, determines PASS/FAIL, and generates PDF reports.Inputs: Data files generated by Software 1 (or manually entered data).Outputs: Interactive graphs, AI diagnostic text, Database records, and PDF QA Reports.3. System Architecture & Data FlowThe system operates in a one-way sequential flow:Test Machine $\rightarrow$ DataStreamer (Software 1) $\rightarrow$ Shared .TXT File $\rightarrow$ Analab Analyzer (Software 2) $\rightarrow$ PDF QA ReportIndependence: The two applications run independently. Software 1 must run during the physical test to record the data. Software 2 can be run at any time after the test is complete to analyze the shared .txt file.4. Quick Start — Perform Your First TestFollow these steps to conduct a standard QA test:Turn on the equipment: Ensure the test machine and sensors are powered.Start Software 1 (DataStreamer): Begin logging data from the machine.Start the physical test: Pressurize the part and allow the test cycle to complete.Save the data: Software 1 will generate a .txt file containing the test data.Start Software 2 (Analab): Open the Analab dashboard.Import Data: Click Import File in the top menu and select your .txt file.Enter Test Info: Type the Part Number and Operator Name into the left panel.Review the Result: Look at the right panel to see if the part shows a green PASS or a red FAIL.Generate Report: Click the red Export PDF button in the top right to save the official report.5. The Pressure Decay Test ExplainedA standard test follows three physical phases, which Analab analyzes automatically:Pressurization (Pump-Up): The machine fills the part with air. Analab ignores this phase to prevent false leak readings.Stabilization: The air settles and cools. Analab scans for the moment the curve flattens out (the "Stable Pressure").Measurement (Decay): The actual leak test. Analab measures from the Stable Pressure down to the end of the test. If the drop is too large, the part fails.10. Graph DocumentationThe center graph is highly interactive.Zoom In/Out: Scroll your mouse wheel while hovering over the graph.Pan/Move: Left-click and drag the graph to move around.Reset View: Middle-click the scroll wheel to instantly snap the graph back to fit all data.Markers: The software automatically drops colored shapes on the line to indicate exactly where it calculated specific events (Blue Circle = Peak, Green Square = Stabilization, Red Diamond = Final).Note: If markers are very close together, the software uses smart collision detection to push one label up and the other down so they remain readable.11. Automatic Analysis (How the Math Works)The software does not guess; it follows strict mathematical rules:Smart Peak Slicing: It finds the highest pressure point and chops off everything before it.Stabilization Detection: It looks for a 10-second window where the pressure bounces by less than your Tolerance setting.The 35% Fallback: If the sensor is too noisy to find a perfect flat spot, it scans the first 35% of the test and locks onto the most stable region it can find.Decay Rate Calculation: It uses a mathematical line-of-best-fit (Polynomial Fit) to calculate the exact speed of the leak per minute.12. Manual Data EntryIf Software 1 fails or you are testing a part by hand with a stopwatch and gauge, click Manual Entry.Type your seconds into the "Time" column and your readings into the "Pressure" column.The software will automatically ignore empty rows or blank spaces to prevent crashes.13. Test Results & MetricsTotal Pressure Drop: Calculated strictly as Stable Pressure - Final Pressure.Thermal Expansion: If a part heats up and pressure rises, the Drop will safely lock at 0.000 to avoid confusing negative drops.Decay Rate: A negative number means pressure is dropping. A positive number means pressure is rising.14. GlossaryDecay Rate: The speed at which pressure is escaping the part, calculated per minute.Jitter: Small, rapid fluctuations in the sensor reading caused by electrical noise or vibration.Micro-leak: A defect so small it is usually invisible on a standard graph but detected by the math engine.Yielding Seal: A part that holds pressure initially, but suddenly begins leaking halfway through the test.21.
